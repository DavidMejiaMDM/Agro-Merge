Diagramas de Secuencia del Sistema

1. Flujo de Acceso (Registro, Verificación y Login)

sequenceDiagram actor U as Usuario participant F as Frontend participant B as Backend (Node.js) participant DB as MySQL participant M as Nodemailer %% Registro y Verificación U->>F: Llena formulario de registro F->>B: POST /registro B->>DB: Guarda usuario (estado inactivo) + PIN B->>M: Envía PIN al correo M-->>U: Recibe código de verificación U->>F: Ingresa PIN en confirmar-codigo.html F->>B: POST /verificar B->>DB: Actualiza estado a 'activo' B-->>F: Redirige a Correo Verificado / Login %% Login U->>F: Ingresa credenciales F->>B: POST /login B->>DB: SELECT * WHERE email=? AND contrasena=? DB-->>B: Usuario válido y activo B-->>F: HTTP 200 (Login Exitoso) F-->>U: Accede al Index Principal

2. Flujo de Compras (Gestión de Carrito y Checkout)

sequenceDiagram actor C as Comprador participant F as Frontend participant B as Backend (Node.js) participant DB as MySQL %% Agregar y quitar C->>F: Clic en "Agregar al carrito" F->>B: POST /carrito/agregar B->>DB: INSERT/UPDATE detalle_carrito B-->>F: Carrito actualizado (HTTP 200) C->>F: Clic en "Quitar producto" F->>B: DELETE /carrito/quitar B->>DB: DELETE FROM detalle_carrito B-->>F: Producto removido %% Checkout C->>F: Clic en "Comprar" (Checkout) F->>B: POST /checkout B->>DB: Crea registro en 'pedidos' B->>DB: Vacía el 'carrito' del usuario B-->>F: Confirmación de Pedido Creado F-->>C: Muestra pantalla de éxito

3. Flujo de Cuenta (Actualizar Perfil y Restablecer Contraseña)

sequenceDiagram actor U as Usuario participant F as Frontend participant B as Backend (Node.js) participant DB as MySQL participant M as Nodemailer %% Restablecer Contraseña U->>F: Solicita restablecer contraseña F->>B: POST /recuperar-password B->>M: Envía enlace o código al correo U->>F: Ingresa nueva contraseña F->>B: POST /actualizar-password B->>DB: UPDATE usuarios SET contrasena=? B-->>F: Contraseña actualizada %% Actualizar Perfil U->>F: Edita datos en Mi Perfil F->>B: PUT /perfil/actualizar B->>DB: UPDATE usuarios / vendedores DB-->>B: Datos guardados B-->>F: Confirmación de actualización F-->>U: Interfaz actualizada con nuevos datos
